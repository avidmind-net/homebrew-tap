# Avidmind Applications tap

Homebrew tap for Avidmind's apps.

## Install

```sh
brew tap avidmind-net/tap
```

Then install whatever you need from the list below.

## Apps

| App | Install | Description |
|---|---|---|
| [Me, Myself & I](https://me-myself-i.com) | `brew install --cask memyselfni` | Personal productivity app for tasks, goals, and trackers |

Prefer the bleeding edge? A beta channel is available for apps that offer one:

```sh
brew install --cask memyselfni@beta
```

Beta and stable versions of the same app conflict with each other — Homebrew
will tell you to uninstall one before installing the other.

## Requirements

macOS Monterey (12) or later.

## Upgrading

```sh
brew upgrade --cask memyselfni
```

## Uninstalling

```sh
brew uninstall --cask memyselfni
```
